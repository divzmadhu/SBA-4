### Reflection

While working on my TaskMate project, I learned more about using JavaScript to create and display elements on a webpage. I also practiced using arrays, objects, event listeners, `createElement()`, `appendChild()`, and localStorage.

I ran into a few errors while working on the project. For example, I used `task[i].deadline` when I should have used `task.deadline`. I also had the Overdue and In Progress conditions mixed up. After going through the code, I was able to understand and fix these errors. I also learned that I needed a counter to keep track of when all the tasks were checked before displaying the updated task list.

There are still a few things I need to finish, including the filtering option, saving the updated status to localStorage, and working on the CSS properties and overall styling of the app. I am still getting more comfortable with the DOM, but this project helped me understand it better.
